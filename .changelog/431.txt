```release-note:fixed
resource/anyscale_cloud: An AWS cloud created with `aws_config.external_id` now records it as the cloud's own external ID, so its services can pass the load balancer step instead of failing with an `sts:AssumeRole` denial. The API cannot change this on an existing cloud: recreate any AWS cloud created by an earlier version with `aws_config.external_id` set (`terraform apply -replace=anyscale_cloud.<name>`).
```

```release-note:changed
resource/anyscale_cloud: Creating a cloud whose `aws_config.external_id` does not start with your organization ID now fails at plan, because the API refuses that value on the cloud itself. Existing clouds are not affected.
```

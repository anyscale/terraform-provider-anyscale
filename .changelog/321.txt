```
release-note:fixed
resource/anyscale_compute_config: Removing a worker group from the middle of `worker_nodes` no longer gives the group that moves into its position the removed group's `name` and `resources`, which were previously sent to the API as if configured.
```

```
release-note:fixed
resource/anyscale_compute_config: An unrecognized `worker_nodes[].market_type` is now rejected at plan time with the accepted values. It used to warn, create the version, and then fail the apply. This is a behavior change the schema does not show; no such configuration could ever apply.
```

```
release-note:fixed
resource/anyscale_compute_config: Per-node `flags` and `advanced_instance_config` now compare by JSON meaning, so valid JSON in any formatting applies without an "inconsistent result" error, and invalid JSON is rejected at plan time instead of being silently dropped. Existing state is unaffected.
```

```
release-note:fixed
resource/anyscale_compute_config: `terraform destroy` on an Azure control plane, where archiving compute configs is not supported, now removes the config from state with a warning instead of failing.
```

```
release-note:fixed
data-source/anyscale_compute_config: `versions` now lists only versions in the config's own cloud, and a lookup by `name` prefers a non-archived config, warning when only an archived one matches.
```

```
release-note:changed
resource/anyscale_compute_config: The `idle_termination_minutes` description now states that removing it from configuration keeps the current value.
```

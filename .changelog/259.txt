```
release-note:breaking-change
resource/anyscale_cloud_user_role: Removed with no replacement. Adopters get no deprecation warning and no diff: Terraform cannot decode the existing state at all and fails with `unsupported-resource-type`. No state upgrader can help, since the type is gone - the safe path is `terraform state rm` on every instance before upgrading to this version. `terraform state rm` does not revoke anyone: it only stops Terraform tracking the grant, leaving the person's cloud access untouched. Removing the resource block and applying, or running `terraform destroy`, issues a real `DELETE` against the backend and revokes that person's cloud access.
```
